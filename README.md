# 8-bit-siso-shift-register
8 bit serial in serial out shift register using verilog
## Features
-8 bit data storage
-serial data input and serial data output
-synchronous operation
-reset functionality

## Tools used
Vivado

## simulation
The design was simulated using a verilog testbench
